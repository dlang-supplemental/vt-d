= vt-d

VT/ANSI escape parser and character-cell screen model for the D programming language.

link:https://github.com/dlang-supplemental/vt-d/issues[Report Bug] ·
link:https://github.com/dlang-supplemental/vt-d/issues[Request Feature]
endif::[]

Package name on DUB: `vt-d`.

== About The Project

`vt-d` turns a byte stream of VT/ANSI escapes into a **character-cell grid** (`Screen` of `Cell`s: glyph, fg/bg, attributes). It is the terminal *emulator screen model* only — no PTY, no window, no GPU.

Use it with link:https://github.com/dlang-supplemental/pty-d[`pty-d`] (Windows ConPTY + POSIX `posix_openpt`) when you need a host. Rendering (for example dew + vello-d) stays in the application.

Still needed for a greenfield D terminal host: wire **ConPTY (`pty-d`) + vt-d + dew** (see OpenShellOrg shell-architecture inventory).

== Features

* Byte stream → VT/ANSI parse (CSI, OSC title subset, SGR colors, cursor, clear, scroll)
* `Screen` / cell grid (char, fg/bg, attrs) with resize and optional scrollback
* UTF-8 printable text
* Zero dependencies beyond Phobos
* Unittests with golden escape sequences

== Usage

[source,d]
----
import vt;

void main()
{
    auto em = new Emulator(80, 24);
    em.feed("\033[31;1mHello\033[0m\n");
    assert(em.screen.at(0, 0).ch == 'H');
    assert(em.screen.at(0, 0).fg == Color.ansi(1));
    import std.stdio : writeln;
    writeln(em.screen.dumpText());
}
----

Demo binary:

[source,shell]
----
dub run -c example-dump -- --demo
----

== Installation

Add to `dub.json`:

[source,json]
----
"dependencies": {
    "vt-d": "~>0.1.0"
}
----

Or `dub.sdl`:

[source,sdl]
----
dependency "vt-d" version="~>0.1.0"
----

== VT subset (v0.1)

* **C0:** BS, HT, LF/VT/FF, CR
* **ESC:** RIS (`c`), DECSC/DECRC (`7`/`8`), IND/NEL/RI (`D`/`E`/`M`)
* **CSI:** CUP/HVP, cursor moves, ED/EL, IL/DL, ICH/DCH/ECH, SU/SD, DECSTBM, SGR (attrs + 16/256/truecolor), IRM, DECSET/DECRST `?25` / `?6` / `?7`
* **OSC:** `0` / `2` titles (BEL or ST)
* **Not yet:** mouse, bracketed paste, most private modes, alternate screen buffer, sixels, full charset G0/G1
